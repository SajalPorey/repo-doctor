# Contributing to RepoDoctor

Thank you for your interest in contributing to RepoDoctor! We welcome all contributions, whether it's fixing bugs, improving documentation, or proposing new features.

## Getting Started

1. Fork the repository and clone it locally.
2. Install dependencies with `npm install`.
3. Create a new branch for your feature or bugfix.
4. Run the development server with `npm run dev`.

## Making Changes

- Ensure your code follows the existing style and conventions.
- Add or update tests as necessary.
- Write clear, concise commit messages.

## Submitting a Pull Request

- Push your branch to your fork.
- Open a Pull Request against the `main` branch.
- Provide a clear description of the problem your PR solves and the changes it introduces.

We will review your PR as soon as possible. Thank you for contributing!
